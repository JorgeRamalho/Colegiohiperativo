# Planejamento

Use esta pasta para artefatos que **não são código**:

- Escopo de funcionalidades e critérios de aceite
- Roadmap por trimestre ou sprint
- Decisões de produto (formato livre ou tabela data + decisão + motivo)

## Modelo sugerido para nova feature

Crie um arquivo `YYYY-MM-nome-curto.md` com:

1. **Objetivo** — o que o usuário ganha
2. **Fora de escopo** — o que não será feito agora
3. **Dependências** — API, infra, design
4. **Checklist de entrega** — UI, API, testes E2E, docs

## Estado atual (referência)

Portal institucional com matrícula, autenticação, cursos, esportes e área do usuário. Infra compartilhada no repositório `infra`.
