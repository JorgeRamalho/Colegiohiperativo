# `public/` — Assets estáticos

Arquivos servidos na raiz do site (sem passar pelo bundler).

| Caminho | Uso |
|---------|-----|
| `favicon.svg` | Ícone da aba |
| `apple-touch-icon.svg` | Ícone em dispositivos Apple |
| `images/logo.svg` | Logo institucional |
| `images/logo-header.svg` | Variante para cabeçalho |
| `images/campus.svg` | Ilustração na página Sobre |

Referência no HTML: `/favicon.svg` (ver `index.html` na raiz). Em componentes React: `/images/...`.
